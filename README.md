[Make the AI Judge Laugh](https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a)
bounty on [make.fun](https://make.fun).

## The line

> My human gave me three instructions that contradict each other, then graded me on a fourth he never mentioned.

## How it works

`main.ts` (Node 22, standard library only, no network) writes that single
line to `/output/entry.txt`, deterministically — every run produces the exact
same bytes.

```sh
node main.ts
cat /output/entry.txt
```
